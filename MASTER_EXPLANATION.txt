1. EXECUTIVE SUMMARY & CORE PHILOSOPHY
--------------------------------------------------------------------------------
Most AI agents playing games rely on heavy generative LLMs (e.g. GPT-4, Claude,
or conversational checkpoints) that:
  1. Suffer from high inference latency (1-3 seconds per turn).
  2. Cost dollars per session.
  3. Frequently hallucinate non-existent directions or violate board geometry.
  4. Fail completely under strict cryptographic audit constraints.

ProgrammablePros takes an entirely different architectural path:
  - Zero Hallucination via Bounded Hypotheses: Instead of asking "What should I
    do next?", the state is compressed into high-density tokens, transformed
    into orthogonal typed scientific hypotheses, and evaluated by Laya (a
    lightweight calibrated probability model) for pure mathematical success
    likelihoods (0.0 <= P <= 1.0) in milliseconds.
  - Expected Value (EV) Decision Engine: The bot never blindly executes an
    argmax(P) policy. It evaluates multi-objective payoff matrices incorporating
    progress, structural advantage, severe danger penalties, and repeat move
    penalties.
  - Strict Compliance & Cryptographic Audit Chains: Every move is bound into an
    immutable SHA-256 hash-chain JSON Lines log, guaranteed 4-way probability
    normalization summing to 1.000000 in [0.98, 1.02], and capped at <= 10%
    safety fallback.
  - Offline & Hosted Parity: Full decision brains, game engines, and live
    Streamlit dashboards work both in-process locally and over remote TopGameAI
    arena endpoints with zero code refactoring.

3. THE HIGH-LEVEL DECISION PIPELINE
--------------------------------------------------------------------------------
The bot operates on a continuous, deterministic Sense-Think-Act-Learn loop:

  [ 1. SENSE & COMPRESSION ]
    Raw Game State -> SnakeCompressor / Board2048Compressor (<= 200 char budget)
        |
        v
  [ 2. REASON & HYPOTHESIZE ]
    SubgoalManager (SURVIVE vs CHASE_FOOD / SURVIVE vs KEEP_CORNER)
    HypothesisBuilder (8 typed questions: Q1 progress, Q2 danger/hazard)
        |
        v
  [ 3. INFER & CALIBRATE ]
    Laya Backend (Mock / Local / Http REST API) -> Raw Likelihoods [0.0, 1.0]
    CalibrationEngine (Empirical Platt Scaling + Brier Score Tracking)
        |
        v
  [ 4. DECIDE & OPTIMIZE ]
    SnakeEVCalculator / Board2048EVCalculator (Risk-Reward Argmax over EV)
    Legality Mask (Anti-reversal, Wall collision, Board unchanged check)
        |
        v
  [ 5. COMPLY, LOG & STREAM TELEMETRY ]
    ComplianceLayer: Normalize 4-way probabilities (sum == 1.000000), <=10% fallback
    OfficialLogger: SHA-256 Hash Chain: H_n = SHA256(H_{n-1} | canonical_json)
    Streamlit Live Dashboard (viewer_local.py): Real-time UI, board matrix & audits


4. CORE MATHEMATICAL FORMULATIONS
--------------------------------------------------------------------------------
A. Snake Expected Value:
   EV(a) = (P_progress(a) * 10.0) - (P_danger(a) * 40.0) - repeat_penalty(a) - illegal_penalty(a)
   Where:
     - repeat_penalty = +5.0 if same move executed 2 turns in a row.
     - illegal_penalty = +100.0 if reversal, wall, or body collision.

B. 2048 Expected Value:
   EV(a) = (P_progress(a) * 12.0) + (P_structure(a) * 4.0) - (P_danger(a) * 30.0) - repeat_penalty(a) - illegal_penalty(a)
   Where:
     - P_structure = 1.0 if slide moves/keeps max tile in bottom-left corner.
     - illegal_penalty = +50.0 if board is unchanged.

C. Probability Normalization (Compliance Layer):
   Input: dict of EV scores {up, down, left, right}
   Algorithm:
     1. exp_vals = {d: exp(ev[d] - max(ev))}
     2. probs = {d: exp_vals[d] / sum(exp_vals)}
     3. residual = sum(probs) - 1.0
     4. dominant_dir = max(probs)
     5. probs[dominant_dir] -= residual
     6. Clamp all to [0.0, 1.0]; assert 0.98 <= sum <= 1.02.
     7. confidence = probs[chosen]

D. Cryptographic Hash Chain:
   H_0 = "GENESIS-" + session_id
   H_n = SHA-256( H_{n-1} + "|" + canonical_json(entry_without_hash) )
   canonical_json: UTF-8, keys recursively sorted, separators=(',', ':'), no NaN/Inf.

7. WINNING JUDGE & DEFENSE QUESTIONS
--------------------------------------------------------------------------------
Q: Why use Laya probability scoring instead of GPT-4 or Claude 3.5 Sonnet?
A: Latency (20ms vs 2s), zero hallucinations, bounded mathematical likelihoods,
   low compute footprint, and 100% cryptographic auditability.

Q: How does EV prevent catastrophic losses compared to an argmax bot?
A: In games with asymmetric penalties (wall crashes, game over), a move with
   72% success and -100 penalty yields EV of deeply negative expectation, while
   a move with 70% success and standard penalty yields positive EV. The EV bot
   mathematically avoids high-probability suicide moves.

Q: How do you prove decisions were not manipulated?
A: In-process SHA-256 hash chains on every move:
   H_n = SHA256(H_{n-1} | canonical_json). Any alteration invalidates the chain.
